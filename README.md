# Miranda Scarola — Virtual Assistant for Therapists

Single-page marketing site for Miranda Scarola's virtual assistant practice.

## Stack
- Static HTML / CSS — no build step.
- Fonts: Cormorant Garamond, Inter, Caveat, JetBrains Mono (Google Fonts).

## Deploy
Static site. Drop into Vercel, Netlify, or Cloudflare Pages with no configuration. Vercel auto-detects the static `index.html`.
